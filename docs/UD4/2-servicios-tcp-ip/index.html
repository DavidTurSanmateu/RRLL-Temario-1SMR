    2. Servicios de infraestructura TCP/IP

    Los servicios de infraestructura TCP/IP proporcionan los mecanismos necesarios para identificar los equipos de una red y configurar automáticamente los parámetros que necesitan para comunicarse. Entre ellos destacan el servicio DNS, encargado de resolver nombres de dominio en direcciones IP, y el servicio DHCP, que automatiza la configuración de los dispositivos de red.

    Estos servicios permiten simplificar la administración de las redes, reducir los errores de configuración y facilitar el acceso a los recursos, independientemente de los cambios que puedan producirse en la infraestructura.

    2.1. Servidores DNS (Domain Name System)

    El sistema de nombres de dominio o DNS (Domain Name System) es un servicio de resolución de nombres que permite identificar los dispositivos y servicios de una red mediante nombres, en lugar de tener que utilizar directamente sus direcciones IP. Su función principal consiste en traducir los nombres de dominio en direcciones IP, aunque también permite realizar otras consultas, como obtener los servidores de correo asociados a un dominio o localizar determinados servicios de red.

    DNS utiliza una estructura jerárquica y distribuida que organiza los nombres en diferentes niveles. Un nombre de dominio completo, denominado FQDN (Fully Qualified Domain Name), está formado por varias etiquetas separadas por puntos. Estas etiquetas se escriben de izquierda a derecha, desde el nivel más específico hasta el más general. Por ejemplo, en el nombre pc.aula.centro.es, pc identifica un equipo concreto, aula representa un subdominio, centro identifica el dominio de la organización y es corresponde al dominio de nivel superior.
